## 📊 1. Quantitative Core & Risk Framework
* **Zero-Forecast Model:** Мы не угадываем направление рынка, а эксплуатируем математическое ожидание, дисбалансы стакана и возврат к среднему (Mean Reversion).
* **Strict Capital Protection:** Фиксированный риск на сделку (0.5%–1.0%), отсутствие мартингейла и институциональный Hard-Stop по просадке.
* **Separately Managed Accounts (SMA):** Управление пулами капитала через некостодиальные шлюзы и Trade-Only API архитектуру (Bybit, Hyperliquid, BingX).
